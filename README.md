
# Quiz Master - C Programming Project

## Introduction
Quiz Master is a simple console-based quiz game developed using the C programming language.

It allows users to answer multiple-choice questions and calculate their final scores.

## Objectives
- Understand basic C programming.
- Practice structures and functions.
- Learn loops and conditional statements.
- Understand arrays and user input.
- Build a simple interactive application.

## Features
- Main menu
- 7 multiple-choice questions
- Four options for every question
- Automatic score calculation
- Correct and incorrect answer feedback
- Final percentage calculation
- Performance message
- Input validation

## Technologies Used
- Programming Language: C
- Code Editor: Visual Studio Code
- Compiler: GCC

## How to Run

Compile the program:

gcc quiz_game.c -o quiz_game.exe

Run the program:

.\quiz_game.exe

## Concepts Used
- Structures
- Arrays
- Functions
- Loops
- If-else statements
- Switch statements
- User input and output
